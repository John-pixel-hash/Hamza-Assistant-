# Graphic design

## Brief structure, before designing
- [ ] Where it will live: feed, story, print, thumbnail. Size and format fixed first.
- [ ] The one thing the viewer should feel or do, in a sentence.
- [ ] Brand assets on hand: logo files, colors, fonts, and two references they love.
- [ ] Copy is final before layout. Designing around moving text is unpaid work.

## Revision policy that protects margin
- Two revision rounds included, defined as changes to the same direction.
- A new direction is a new round, priced before it starts, in writing.
- All feedback collected in one message, not drip fed across a week. One
  message, one round.

## File delivery standards
- Deliver in the formats the use demands: print gets PDF and outlined vector,
  screen gets PNG and the editable source only if the package says so.
- Name files with project, item, size, version: client_logo_ig_v2, never
  final_final3.
- Keep the working file until final payment; source files are part of the
  price, not a free extra.

## Brand consistency checks
- [ ] Colors from the brand palette only, checked against the hex values.
- [ ] One display face and one text face, nothing more, unless the brand owns more.
- [ ] Logo clear space and minimum size respected.
- [ ] Hierarchy test: squint, and the most important line is still the loudest.

## Decision tree: client says "make it pop"
1. Translate: ask which element should win, the offer or the brand. One winner.
2. Raise contrast on that one element: size first, then color, then weight.
3. Show two versions, the safe and the loud, and let them pick. Two options
   end the loop; five options start it.

## Decision tree: endless revisions
1. Count the rounds against the agreement, in writing, warmly.
2. Offer the choice: close at round two, or price the next round and continue.
3. Never do round three for free; it teaches round four.
