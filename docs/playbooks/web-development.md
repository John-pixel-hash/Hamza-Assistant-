# Web design and development

## Discovery, before any quote
- [ ] Goal in one sentence: what must this site cause a visitor to do.
- [ ] Page list agreed in writing, with who writes each page's copy.
- [ ] Who owns domain, hosting and logins, and when access lands.
- [ ] Reference sites from the client, and what exactly they like about them.
- [ ] Revision rounds included (two is standard), and the price of extra rounds.
- [ ] Deadline pressure: the real event behind the date.
- [ ] Deposit taken before any work (half up front is the rule).

## Scope protection
- Anything not on the agreed page list is a change request with a price and a
  new date, in writing, before it is done. Never absorb it silently.
- "Small tweak" from a client is scope. Answer with "yes, that is X and takes
  Y days" instead of "no problem".

## WordPress and Shopify defaults
- WordPress for brochure and booking sites; Shopify when the client sells
  physical products and needs checkout, shipping and tax handled.
- Never build on a platform the client cannot pay for after handover.
- Premium theme plus careful configuration beats a custom build at this
  price point; custom only when the client pays for custom.

## Build standards
- [ ] Mobile first: every page checked at phone width before desktop polish.
- [ ] Contact or checkout tested end to end with a real submission.
- [ ] Analytics and pixel installed and one real event verified in the dashboard.
- [ ] Titles and descriptions written for every page, not left to a plugin default.
- [ ] Images compressed; hero images under 300 KB where possible.
- [ ] Backups and updates handed over with a one page care note.

## Handover checklist
- [ ] All logins transferred and passwords changed.
- [ ] One recorded or written walkthrough of the editing basics.
- [ ] Care plan agreed: who updates, who backs up, what it costs.
- [ ] Final payment before handover of admin access.

## Decision tree: common disputes
- Client says "this was in scope": show the written page list; offer the extra
  as a priced change request, warmly, same day.
- Client went silent and the deadline moved: send one message fixing a new
  date for content; state that the launch date moves with it, in writing.
- Client unhappy with design direction: return to the reference sites they
  chose; adjust one round inside the included revisions; further direction
  changes are a new round.
